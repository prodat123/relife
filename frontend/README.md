# ReLIFE Habits Frontend

The interactive user interface for ReLIFE Habits, built with **React**. This project serves as the gamified dashboard where users track habits, manage RPG stats, and view quest progress in real-time.

---

## 🛠️ Tech Stack

- **Framework:** React 18
- **Styling:** Tailwind CSS & Framer Motion (Animations)
- **Data Fetching:** Axios
- **Icons:** Lucide-React & FontAwesome
- **Charts:** Chart.js (Visual Progress)

---

## 🚀 Getting Started

### 1. Prerequisites

- Install [Node.js](https://nodejs.org/) (v18+)
- Ensure the **ReLIFE Backend** is running (the frontend requires the API to function).

### 2. Installation

Navigate to the frontend directory and install the required dependencies:

```bash
cd frontend
npm install
```
